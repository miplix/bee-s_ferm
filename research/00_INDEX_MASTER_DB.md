## 1. Базовые константы SFL

### 1.1 Максимум персонажа

- **MAX_BUMPKIN_LEVEL = 200** (`src/features/game/lib/level.ts`)
- **Макс. XP = 244 206 000**
- 1 очко навыка за уровень → максимум 200 skill points
- Основа прокачки: поедание блюд, приготовленных в кухонных зданиях

### 1.2 Базовые кулдауны ресурсов (без бустов)

| Ресурс | Кулдаун | Источник |
|-------|---------|---------|
| Дерево | 2 часа | `chop.ts` `CHOP_RECOVERY_TIME` |
| Камень | 4 часа | `stoneMine.ts` |
| Железо | 8 часов | `ironMine.ts` |
| Золото | 24 часа | `mineGold.ts` |
| Кримстоун (1 из 5 в цикле) | 24 часа, после полного цикла +24ч | `mineCrimstone.ts` |
| Санстоун | 72 часа | `mineSunstone.ts` |
| Нефть | 20 часов | `drillOilReserve.ts` |

### 1.3 Ёмкость зданий-животных

Формула: `capacity = 10 + (buildingLevel − 1) × 5` → **10 / 15 / 20** на уровнях 1/2/3.

- Hen House: старт 10 кур. Апгрейд ур.2 — 7.500 монет. Апгрейд ур.3 — 50.000 монет.
- Barn: старт 10 коров+овец. Апгрейд ур.2 — 10.000 монет. Апгрейд ур.3 — 75.000 монет.
- Ульи (Beehives): хардкап **3** по всем экспансиям (проверено в `expansionNodes.ts`).

### 1.4 Сон животных

- `ANIMAL_SLEEP_DURATION = 24 часа` базово
- Буст-цепочка (применяются в порядке): El Pollo Veloz −2ч (флат) → Speed Chicken ×0.9 → Dream Scarf ×0.8 → Farm Dog ×0.75 → Mammoth ×0.75 → Wrangler ×0.9 → Collie/Bantam Shrine ×0.75

## 6. Навыки (Bumpkin Skills — revamp)

- **12 деревьев, 3 тира в каждом**
- 1 skill point за уровень (итого до 200)
- Стоимость: Tier 1 = 1pt, Tier 2 = 2pt, Tier 3 = 3pt
- Тиры разблокируются по количеству потраченных точек в дереве:
  - Trees/Fishing/Cooking/Fruit/Bees/Greenhouse/Machinery: 2 → 5
  - Crops/Mining/Compost/Aging: 3 → 7
  - Animals: 4 → 8

Всего ~130 навыков. Ключевые формульные:

- **Green Thumb** ×0.95 грядки (рост)
- **Seed Specialist** ×0.9 всем грядкам
- **Lumberjack's Extra** +0.1 дерева
- **Golden Touch** +0.5 золота
- **Instant Growth** (Power Skill, cooldown 72 ч, Luna's Crescent делит на 2)
- **Strong Roots** ×0.9 продвинутым грядкам
- **Chonky Scarecrow** расширяет AOE пугала 3×3 → 7×7

Полный список — `research/06_skills_deliveries_seasons.md`.

## 8. Формулы стакинга бустов (важнейшее для клона)

Порядок применения (из `harvest.ts` и т.п.):

1. **База** из `CROPS[crop].harvestSeconds` / `node.amount`
2. **Multiplicative** бусты ×... (сначала)
3. **Flat additive** +... (потом)
4. **RNG roll** на каждый шанс-буст независимо (`prngChance`)
5. **Calendar events** (Insect Plague ×0.5, Bountiful Harvest +1 и т.п.)

### 8.1 Пример формулы роста грядки (`getCropPlotTime`)

```
base = CROPS[crop].harvestSeconds
boosted = base
  * (Seed Specialist ? 0.9 : 1)
  * (Nancy/Scarecrow/Kuebiko ? 0.85 : 1)
  * (Lunar Calendar ? 0.9 : 1)
  * (Super Totem|Time Warp Totem ? 0.5 : 1)
  * (Harvest Hourglass ? 0.75 : 1)
  * (Strong Roots ? 0.9 : 1)  // advanced crops
  * (Green Thumb ? 0.95 : 1)
  * (Basic Scarecrow AOE ? 0.8 : 1)
  ... etc
```

### 8.2 Ключевые Power-Skill cooldown'ы

- **Instant Growth**: 72 ч (÷2 с Luna's Crescent)
- **Time Warp Totem**: 2 часа длительность
- **Super Totem**: 7 дней длительность (взаимоисключимы с Time Warp)
- **Harvest Hourglass**: 6ч, **Timber Hourglass**: 4ч, **Ore**: 3ч

## 9. Известные ограничения / серверные участки

Часть логики SFL живёт на сервере и недоступна в open-source клиенте:

- **Шанс болезни животных** — сервер
- **Шанс мутанта-курицы** (~1/1000 базово, ×2 с Barn Manager) — сервер, в клиенте только обработка результата
- **Дроп-таблицы Treasure Island** (пещеры, раскопки) — сервер
- **Генерация заказов доставки** — backend (`deliver.ts:210` коммент)
- **Курс сырья → монеты** (`sellMarketResource.ts`) — серверный dynamic market API

Клон должен реализовать эти места **детерминированно на клиенте** (PRNG с сидом) или держать свой серверный эндпоинт.

## 11. Приоритет синхронизации клон↔SFL

**МАКСИМАЛЬНОЕ соответствие (копировать точно)**:
- Таблица XP уровня 1–200
- Порядок разблокировки культур (какая на каком уровне)
- Порядок разблокировки зданий
- Соотношения времён роста культур (порядок, пропорции)
- Ёмкость животных (формула `10 + (lvl-1)*5`)
- Формулы стакинга бустов (multiplicative → additive → RNG → calendar)
- Порядок разблокировки экспансий
- Система навыков (деревья, тиры, стоимость очков)

**ЧАСТИЧНОЕ соответствие (адаптировать под свою экономику)**:
- Цены в монетах (в ТЗ завышены под Пыльцу/ДаРаи)
- Количество ульев (ТЗ = 8, SFL = 3)
- Кулдауны ресурсов (у ТЗ длиннее под медленный P2E)
- Дроп пыльцы (ТЗ-специфично)

**НЕ копировать (свои механики)**:
- NEAR ДаРаи токен вместо MATIC/SFL/POL
- Пыльца как отдельная валюта и донатная механика
- Принцип "донат-игрок за ~6 мес"
- Ограниченные ульи как главная донатная механика
