# Правила проекта: Пчело-ферма (NEAR)

> Проект-клон Sunflower Land с собственной механикой **Пыльцы** и токена **ДаРаи** (NEAR-экосистема). Все игровые механики — офчейн. Он-чейн только ввод/вывод пыльцы.
>
> База знаний: `research/00_INDEX_MASTER_DB.md` + 12 детальных файлов исследования. Эти rules опираются на ТЗ `TZ_FarmGame_v1.pdf` + собранные SFL-данные.

---

## R0. Общие принципы

### R0.1 Единственный источник истины для механик SFL
- При реализации любой механики, похожей на SFL, **обязательно** сверяться с `research/00_INDEX_MASTER_DB.md` и соответствующим детальным файлом.
- Если в проекте данные расходятся с SFL — это должно быть сознательным решением и задокументировано в `research/00_INDEX_MASTER_DB.md` в секции "Несоответствия".
- **Авторитетный источник**: код SFL в `github.com/sunflower-land/sunflower-land/main`. Community wiki — вторичен.

### R0.2 Язык и именование
- UI: русский (ТЗ 11).
- Код: английский (идентификаторы, типы, поля).
- Идентификаторы предметов/культур/зданий должны совпадать с SFL (`sunflower`, `potato`, `henhouse` и т.д.) для удобства сравнения логики.

### R0.3 Онлайн vs офлайн
- **Все игровые механики — офчейн** (ТЗ 1). Состояние хранится в `localStorage` + серверный backup (если появится).
- Взаимодействие с блокчейном NEAR: только ввод ДаРаи (донат) и вывод пыльцы (через `near-api-js`).

### R0.4 Детерминированность
- Все RNG должны использовать **seeded PRNG** (аналог `prngChance` у SFL). Сид = `userId + timestamp_bucket + actionId`.
- Нельзя полагаться на `Math.random()` для игровой логики — только для визуальных эффектов.

## R2. Культуры и семена

### R2.1 Данные из ТЗ
Таблицы 3.1–3.3 в `TZ_FarmGame_v1.pdf` — **базовые значения**. Применяются как есть для:
- Время роста (1 мин → 48 ч)
- Урожай (1–12 ед)
- Цена семян (завышена относительно SFL, под экономику Пыльцы)
- Цена продажи

### R2.2 Сезонность
- 4 сезона, каждый = 7 реальных дней (ТЗ 3.4).
- Начальный остров — всегда Весна.
- Полная сезонность разблокируется после перехода на 2-й остров (Лепестковый, ур.11+).
- Пшеница — всесезонная.
- Тыква — только осенью (+можно купить на рынке за монеты).

### R2.3 Грядки
- 1 грядка = 1 клетка. 1 культура/грядка.
- **Водяной колодец обязателен** для активации лишних грядок сверх 5 стартовых (ТЗ 6.1).
- Одна культура за раз; повторная посадка после сбора.
- Запрет снять культуру досрочно (кроме как Rapid Root и подобных ускорителей в будущем).

### R2.4 Боевые боссы семян ("SHOP_LIMITS")
Существующая таблица `SHOP_LIMITS` в `src/data/crops.ts` (строки 134–152) — **оставить как есть** для базового старта. При добавлении новых семян расширять таблицу.

## R3. Подножные ресурсы

### R3.1 Таблица ресурсов (ТЗ 5.1)
Использовать ТЗ-значения, **НЕ** SFL-значения:

| Ресурс | Кулдаун ТЗ | Кулдаун SFL | Клон |
|-------|-----------|------------|------|
| Дерево | 4 ч | 2 ч | **4 ч** (ТЗ) |
| Камень | 24 ч | 4 ч | **24 ч** (ТЗ, исчерпаемый ресурс) |
| Железо | 48 ч | 8 ч | **48 ч** (ТЗ) |
| Золото | 72 ч | 24 ч | **72 ч** (ТЗ) |

Причина: экономика клона медленнее SFL, дает место донатной механике Пыльцы.

### R3.2 Исчерпаемые vs возобновляемые ноды (ТЗ 5.1)
- **Дерево**: бесконечно, 5 ед за рубку, кулдаун 4 ч.
- **Камень**: 1 нода = 20 ударов → исчезает; новые после расширения.
- **Железо**: 10 ударов → исчезает.
- **Золото**: 5 ударов → исчезает.
- После **расширения** исчерпанные ноды восстанавливаются (ТЗ 4).

### R3.3 Инструменты (одноразовые)
ТЗ 5.1 — все инструменты сжигаются за 1 использование:
- Топор: 3 дерева
- Каменная кирка: 3 дерева + 3 камня
- Железная кирка: 3 дерева + 5 камней
- Золотая кирка: 5 дерева + 5 камней + 5 железа

Для SFL эквивалентны, но SFL добавляет +20 coin к каждому — **игнорировать** (ТЗ без монет).

## R4. Расширение территории (ТЗ 4)

### R4.1 Правила
- **Дефляционный принцип**: камень/железо/золото **нельзя** выгодно продавать сразу — только тратить на расширения.
- Расширения — единственный способ получить больше грядок и нод.
- Каждое расширение **восстанавливает** все исчерпанные ноды на текущей территории.
- Всего на Базовом острове 9 расширений (ТЗ 4.1).

### R4.2 Стоимости расширений
Таблица ТЗ 4.1 — источник истины. Диапазон: 5 дерева → 60 дерева + 35 камней + 9 железа + 1 золото.

### R4.3 Переход на следующий остров
- Базовый → Лепестковый: **10 золота**
- Лепестковый → Пустынный: **20 Кримстоуна**

(Кримстоун появляется на Лепестковом — нужно добавить при реализации 2-го острова.)

## R6. Кулинария

### R6.1 Рецепты ТЗ 2.2 — обязательные
Все 8 блюд из ТЗ 2.2 **должны быть реализованы**:

- Тыквенный суп (24 XP × 10 тыкв/ч = 240 XP/ч при одной грядке)
- Пример из ТЗ: ~600 XP/ч при массовой готовке
- Молочная каша / Медовый пирог — late-game (нужны коровы / пчёлы)

### R6.3 Время приготовления

  - Пекарня: 20–60 мин
- При отсутствии нагрузки — **мгновенное приготовление** допустимо на MVP.

### R6.4 Запрет продажи еды
Еда **не продаётся за монеты**. Только:
- Кормление персонажа → XP
- Доставки (при будущей реализации) → награда

## R8. Пчелиные домики и Пыльца

### R8.1 Демо-домик (старт, бесплатно)
- Добыча: 0.3–0.5 пыльцы/день
- +1% урожая в радиусе 1 клетки (12 соседей)
- Лимит: 1 действие каждые 8 ч (3 раза/сутки)
- 1000 действий (0%→100%) → превращается в Ур.1
- Instant upgrade: 1000 пыльцы (= 1 пыльца за каждое недоделанное действие)

### R8.2 Платный Ур.1 (ур.10)
- Покупка: 1000 пыльцы
- Добыча: 1000 пыльцы/день (**примечание**: в ТЗ разные упоминания — 5/день пассивно с доната, и 1000/день из самого домика. См. R8.4.)
- +10% урожая в радиусе 1 клетки
- 2×2 клетки

### R8.3 Лимит домиков по уровню (ТЗ 9.3)
| Ур.перс. | Макс. |
|----------|------:|
| 10 | 1 |
| 15 | 2 |
| 25 | 3 |
| 30 | 4 |
| 35 | 5 |
| 40 | 6 |
| 45 | 7 |
| 50+ | 8 |

После ур.60: +1 слот/10 ур. до 100 (→ 12 слотов к 100). После 120: +1 слот/20 ур. до 200 (→ 16 к 200).

### R8.4 Добыча пыльцы — уточнение
ТЗ содержит два значения:
- **ТЗ 9.2**: "Добыча: 1000 пыльцы в день" (с одного домика)
- **ТЗ 9.6**: "Задонатив 1000 пыльцы → в день начинаешь добывать 5 пыльцы пассивно"

Разрешение: 1000 пыльцы в сутки — это не "с домика", а из **общей донатной механики**:
- Задонатил 1000 → +5 пыльцы/день пассив (0.5%/день)
- 1000 пыльцы = 1 домик → +X пыльцы/день из домика
- Считаем X = **5 пыльцы/день** на 1 домик Ур.1 (синхронно с коэффициентом доната)

Значения нужно финально согласовать с заказчиком.

### R8.5 Объединение (ТЗ 9.4)
- 2× Ур.1 → 1× Ур.2: 9 пыльцы/день (-10% от 10), 1 слот (освобождает 1)
- 2× Ур.2 → 1× Ур.3: 16.2 пыльцы/день (-10% от 18)
- Объединять выгодно **только** если есть новый домик в освободившийся слот

### R8.6 Пассивный буст к грядкам (ТЗ 9.5)
- Ур.1: +10% в радиусе 1 клетки
- Ур.2: +15%
- Ур.3: +20%
- ... каждый следующий уровень +5%
- **Бусты суммируются**, если грядка в радиусе нескольких домиков
- Оптимум: шахматный порядок

### R8.7 Активный буст
1 пыльца = x2 к ОДНОЙ грядке при сборе (1-кратно). Пыльца списывается.

## R12. Правила кода

### R12.1 Структура файлов
```
near-farm/src/
├── data/                  # Константы игры (CROPS, RECIPES, TOOLS, BUILDINGS, ...)
│   ├── crops.ts           # [существует] культуры, уровни, рецепты, ноды, инструменты
│   ├── animals.ts         # [добавить] куры/коровы
│   ├── beehives.ts        # [добавить] пчелиные механики
│   ├── expansions.ts      # [добавить] расширения (Basic)
│   └── boosts.ts          # [добавить] формулы стакинга
├── hooks/
│   └── useGame.ts         # [существует] main game state hook
├── components/            # [добавить] UI-компоненты
│   ├── Farm.tsx
│   ├── Inventory.tsx
│   ├── BuildingPanel.tsx
│   ├── HenHouseScreen.tsx
│   ├── BarnScreen.tsx
│   └── BeehivePanel.tsx
├── lib/
│   ├── prng.ts            # [добавить] seeded PRNG
│   ├── boostEngine.ts     # [добавить] чистая функция apply_boosts(base, ctx)
│   └── near.ts            # [добавить] NEAR wallet connection
└── App.tsx
```

### R12.2 Чистота функций
- Все формулы бустов — **чистые функции** без side-effect
- Пример сигнатуры: `computeCropYield(base: number, ctx: BoostContext): number`
- `BoostContext` включает: collectibles, wearables, skills, calendar, chapter, bud, active totems

### R12.3 Time-based логика
- Всё время — в **миллисекундах** через `Date.now()`
- Не использовать `setTimeout` для game logic — только для UI effects
- Game state хранит `plantedAt`, `cooldownUntil` как `number` (ms)

### R12.4 Сериализация состояния
- JSON-сериализуемое состояние → `localStorage`
- Backup в IndexedDB для больших стейтов
- Миграция: каждое поле с default-value, версия стейта в поле `version`

### R12.5 Readability / конвенции
- TypeScript `strict: true` (проверить `tsconfig.json`)
- Never use `any` без причины
- Enum-поля (`CropId`, `BuildingId`) через string union types, не enum
